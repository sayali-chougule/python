# python
### 1.1 Some common type codes are:

| Type code | Meaning                     | Example      |
| --------- | --------------------------- | ------------ |
| `'i'`     | Integer                     | `1, 2, -10`  |
| `'f'`     | Float                       | `1.5, 2.7`   |
| `'d'`     | Double-precision float      | `1.23456`    |
| `'b'`     | Signed char / small integer | `1, -5, 100` |
| `'u'`     | Unicode character           | `'a', 'b'`   |
